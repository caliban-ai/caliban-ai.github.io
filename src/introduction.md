# caliban-ai

caliban-ai is a small constellation of Rust projects for building agent systems:

- **[caliban](./projects/caliban.md)** — a Rust-native, provider-agnostic agent harness.
- **[prospero](./projects/prospero.md)** — orchestration layer.
- **[gonzalo](./projects/gonzalo.md)** — robust, shareable persistence layer for caliban.

See **[Development Updates](./updates/index.md)** for board-review progress reports.
